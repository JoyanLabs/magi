## Cómo Editar los Diagramas

### Opción 1: draw.io online
1. Ve a https://app.diagrams.net/
2. Importa el archivo XML del diagrama
3. Edita y guarda

### Opción 2: MCP Draw.io (recién configurado)
Una vez que reinicies OpenCode, puedes crear nuevos diagramas directamente desde el chat usando el MCP de Draw.io.
